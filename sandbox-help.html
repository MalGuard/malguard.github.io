STATIC SCAN SUPPORT

Understand incomplete analysis.

The current clean-room Windows scanner never executes a selected file. Windows Sandbox, sample execution and historical Plus/Pro certification are not requirements for this release.

Installation and scan troubleshooting

Keep protection enabled

Do not disable Defender, Smart App Control, organization policy or installer integrity checks. Follow the verified release guide and report the exact error when installation is blocked.

Read the incomplete stage

INVALID describes an absent or malformed expected structure. INCONCLUSIVE describes insufficient analysis. Encrypted members, unsupported formats, parser disagreement, worker failure and exhausted budgets can prevent SAFE.

Evidence already collected is retained. A failed parser or unreadable child cannot erase a stronger harmful finding.

Share a bounded report

Provide the build code, Windows version, exact error, file type and SHA-256 when reporting a false positive or bug. Redact personal paths and tokens. Never attach real malware to a public issue.

Support

Local analysis and online intelligence

The engine analyzes files locally. Its updater downloads authenticated signed metadata and rejects rollback. It does not upload scanned files or reports. No AI or cloud sample-execution adapter is configured in this release.
