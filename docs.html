Analysis models

Standard → Plus → Pro

Depth increases only when the release and host can support it. Missing isolation or required evidence must not be silently treated as a successful clean result.

01

Standard

Core file identity, bounded static inspection and security signals for supported workflows.

02

Plus

Staged deeper analysis with bounded progress and routing of suspicious or inconclusive cases toward isolation.

03

Pro

Isolation-first orchestration after integrity preflight where release-grade host evidence is actually available.

Contributors

Defensive development only.

The repository forbids adding, downloading or executing real malware in development or CI. Use harmless synthetic fixtures and run the engineering suite before proposing security-sensitive changes.
