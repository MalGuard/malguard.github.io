Support

Route the problem to the right place.

Security issues, false positives and product bugs need different information. MalGuard does not use a fake contact form or silently discard submissions.

PRIVATE FIRST

You found a security problem

Use the security policy. Include the affected version/commit, harmless reproduction steps, expected behavior and observed behavior. Do not upload real malware.

Security reporting
FALSE POSITIVE

MalGuard got a file wrong

Report the product/version, file type, SHA-256, where you obtained the file, the verdict you received and which finding you disagree with. Never attach real malware to a public issue.

Report false positive
BUG

Something is broken

Include operating system, MalGuard version, steps to reproduce, expected behavior and actual behavior. Redact personal data and secrets from screenshots or logs.

Report a bug
IDEA

Feature request or general feedback

Explain the gaming-security problem first, then the feature you think would solve it. This makes requests easier to evaluate without inventing capabilities that do not exist yet.

Request a feature
