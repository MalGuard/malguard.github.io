SUPPORT / MALGUARD AI

Help Center

Find practical fixes for common MalGuard AI issues. These steps do not guarantee that third-party AI providers are available.

Model unavailable · HTTP 404 / 503
  1. Open Settings → Permissions and privacy.
  2. Enable Free Fallback if you agree to send the conversation to another configured free provider.
  3. Retry once, or select another model in Chat, Work, or Code.
  4. If the issue persists, report the model name, approximate time and error code. Never send API keys or passwords.

A model listed as available may still have no usable provider endpoint. Free fallback can also fail.

Where is Free Fallback?
  1. Open MalGuard AI.
  2. Open the settings icon in the top header.
  3. Expand Permissions and privacy.
  4. Find the checkbox beginning “On provider failure…” and enable it.

Fallback is optional and may share your conversation with a different provider. No paid-model fallback is intended.

Response fails, times out or is incomplete
  1. Check your connection.
  2. Retry once without repeatedly sending the same message.
  3. Try a different available model.
  4. If it persists, note the exact error and contact support.
Models missing from Chat, Work or Code

Refresh the model list or reload MalGuard AI. A model can be listed but temporarily unavailable upstream. If the expected model is still missing, report the model name and mode to support.

Sign-in or session problems

Reload the page and sign in again if prompted. Check whether cookies or site data are blocked. If a session repeatedly expires, send the approximate time and browser version to support, but never share credentials or session tokens.

Install MalGuard AI on iPhone or iPad
  1. Open malguard.site/ai/ in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen and confirm.

On supported iOS versions you may see an option to open as a web app.

Free tier, quotas and provider limits

Free model availability, rate limits and usage allowances depend on the provider and can change. Enabling Free Fallback does not increase provider quotas or guarantee a response.
