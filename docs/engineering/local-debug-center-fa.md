# مرکز بررسی خطای محلی MalGuard

## دیدن لاگ‌ها
صفحهٔ محلی http://127.0.0.1:8788 را باز کنید. «ساخت خطای آزمایشی» یک خطای مصنوعی می‌سازد. شناسهٔ آن را در بخش جست‌وجو وارد کنید. Copy Safe Debug Report فقط فرادادهٔ پاک‌سازی‌شده را کپی می‌کند؛ متن چت، فایل، ایمیل و کلید داخل گزارش نیست.

## اجرای محیط
از ریشهٔ مخزن با Node 24 و وابستگی‌های توسعهٔ نصب‌شده اجرا کنید:

```sh
node tools/engineering-staging/server.mjs --port=8788
```

برای اجازهٔ تحلیل متادیتای مصنوعی با دو مدل موجود، گزینهٔ `--connect-model` را اضافه کنید. سقف هر اجرای برنامه ۶ فراخوانی، هر تحلیل ۲ فراخوانی و هم‌زمانی یک تحلیل است. برنامه فقط روی 127.0.0.1 گوش می‌دهد؛ آن را با تونل یا پراکسی عمومی منتشر نکنید. خاموش‌کردن برنامه همهٔ داده‌های آزمایشی و لاگ‌های حافظه را حذف می‌کند.

اگر npm روی این لپ‌تاپ موجود نیست، بستهٔ PGlite رسمیِ از پیش دریافت‌شده را با متغیر MALGUARD_TEST_PGLITE به مسیر work/db-test-runtime/pglite معرفی کنید و از Node موجود در محیط Codex استفاده کنید. هیچ کلید Supabase یا فایل تنظیمات Production لازم نیست.

## مرزهای واقعی
این محیط PostgreSQL تعبیه‌شده دارد؛ Supabase ابری نیست. انتقال Storage شبیه‌سازی می‌شود و نتیجهٔ تست آن تأیید RLS سرویس واقعی نیست. ایمیل‌ها فقط در حافظهٔ آزمایش نگهداری می‌شوند و ارسال نمی‌شوند. آزمون حساب‌ها در هر اجرای برنامه حداکثر ۱۰ بار مجاز است.

AI اول تشخیص احتمالی می‌دهد و مدل دوم آن را مستقل نقد می‌کند. خروجی مدل متن غیرقابل‌اعتماد است. اجرای کد، ساخت PR توسط محصول و انتشار خودکار هنوز پیاده‌سازی نشده و وضعیت MANUAL REVIEW باقی می‌ماند. نبود پاسخ معتبر، اتمام سهمیه یا قطع سرویس هرگز به معنای رفع باگ نیست.

## لاگ سایت واقعی
اصلاح ثبت لاگ در PR 293 هنوز منتشر نشده است. پس از استقرار تأییدشده، در ابزار توسعهٔ مرورگر، Network و درخواست چت، هدر پاسخ X-Request-ID را بردارید و همان شناسه را در Runtime Logs پروژهٔ API در Vercel جست‌وجو کنید. مخزن محلی رخدادها بین نمونه‌های سرور مشترک نیست؛ نگهداری Vercel نیز به تنظیمات و پلن حساب بستگی دارد. صفحهٔ حاضر لاگ Production را نمایش نمی‌دهد و هیچ دسترسی مدیریتی ابری ایجاد نمی‌کند.

## بازگشت
این ابزار مستقل است؛ برای توقف Ctrl+C بزنید. هیچ migration روی دیتابیس واقعی اجرا نمی‌کند. تغییرات شاخه را می‌توان بدون تغییر سایت عمومی کنار گذاشت.


## صفحهٔ گزارش و پاسخ اولیه
مسیر `/report` فرم جداگانهٔ شرح مشکل و مراحل تکرار را نشان می‌دهد. پس از رضایت صریح، متن محدودشده به مدل موجود cf_qwen3 در Cloudflare ارسال می‌شود. حذف الگوهای رایج ایمیل، URL و کلید جایگزین خودداری از نوشتن اطلاعات محرمانه نیست. این مسیر توکن مخصوص دارد و توکن آن اجازهٔ خواندن API لاگ یا اجرای آزمون حساب را ندارد.

نسخهٔ فعلی فقط محلی است: گزارش به تیم پشتیبانی تحویل نمی‌شود، ذخیرهٔ دائمی و تاریخچه ندارد، و شناسهٔ پاسخ امکان بازیابی بعدی نمی‌دهد. پاسخ در همان صفحه است و رفع باگ را تأیید نمی‌کند. با خاموش‌بودن مدل یا قطع سرویس پیام صریح نشان داده می‌شود. حداکثر شش درخواست مدل در هر اجرای برنامه برای این فرم، هم‌زمانی یک، مهلت ۳۰ ثانیه و بدون تلاش مجدد خودکار است؛ این سقف از شش فراخوانی تحلیل‌گر مدیریتی جداست. سقف مجموع دو قابلیت ۱۲ است.

برای انتشار عمومی، ذخیرهٔ خصوصیِ دارای کنترل مالکیت، دریافت گزارش برای مدیر، سهمیهٔ سراسری/کاربر، ضدسوءاستفاده، نگهداری و حذف گزارش و مسیر Production بررسی‌شده لازم است. ابزار محلی را عمومی نکنید.
