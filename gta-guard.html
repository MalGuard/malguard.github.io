Current platform support

Windows 10 and 11, x64. English is the default; Persian is selectable. Other languages and scanner platforms are not included in this release.

Installation requirements

One static evidence pipeline

Bounded intake and reputation run before deeper analysis. PE, .NET, native capabilities, scripts and nested archives contribute typed evidence. Correlation, coverage and independent harm families determine the verdict.

No scanned code is executed. Parser failures, encrypted members and exhausted work budgets block a clean result when required analysis is incomplete.

Parser isolation, static analysis only

Windows parser workers use bounded IPC and Job Object resource limits. This release has no sample-execution mode. Historical Standard, Plus and Pro descriptions do not describe this clean-room engine.

Know the limits

SAFE means no evidence of malicious behavior was found by completed static analyses. It is not a guarantee of safety.

Static analysis cannot reliably recover every encrypted payload, runtime-generated string or hidden target. Unsupported formats and incomplete analysis remain visible in the report. Accuracy on a representative real-world corpus has not been measured. No AI detection or perfect-protection claim is made.
