HYBRID ISOLATION V1

Local execution first. Disposable cloud inspection only when you choose it.

GTA Guard keeps behavioral execution fail-closed. A Windows file is executed only after the local Windows Sandbox passes containment, isolation and harmless execution certification. If local behavioral isolation is unavailable, Plus and Pro can optionally continue with non-executing Cloud Inspection in a fresh ephemeral environment that is destroyed after the job.

01

Verified local Sandbox

Preferred path for behavioral analysis. Network, clipboard and mapped input remain restricted, and real execution proof is required before behavioral results can affect the verdict.

02

Disposable Cloud Inspection

Optional fallback for bounded non-executing inspection. The cloud job uses deny-all networking, no host fallback and a disposable environment that is destroyed after completion.

03

Fail closed

Cloud Inspection does not execute Windows samples and cannot promote incomplete evidence to SAFE. If behavioral execution was not proven, GTA Guard keeps that limitation visible.

Privacy boundary: Cloud Inspection is opt-in because it uploads a bounded copy of the selected file. Standard scanning remains local. Use the local Sandbox path when you do not want a file to leave the PC.

Analysis models.

Standard

Fast local inspection for supported files and common structural signals.

Plus

Deeper staged analysis and correlation, with fail-closed handling when stronger evidence is needed.

Pro

Direct isolation-oriented analysis when a release-grade backend is available and certified.

What the preview does not promise.

A clean scan reduces risk but does not prove a mod is harmless. Platform capabilities can differ, and unavailable isolation backends fail closed rather than being presented as equivalent protection.
