02 / ONE STATIC EVIDENCE PIPELINE

Go beneath the filename.

Supported static checks inspect file structure, native capabilities, scripts and nested archives. Reputation is one input; evidence and analysis coverage inform the decision.

01 / IDENTIFY

Establish identity.

Understand the supported file type before deeper inspection. A name or hash does not establish safety.

02 / INSPECT

Expose the structure.

Inspect static structure without running the scanned code. Unsupported formats and incomplete analysis stay visible.

03 / ANALYZE

Connect the evidence.

Correlation, coverage and independent harm families contribute to the decision. A blocklist is only one analysis stage.

04 / DECIDE

Keep the limits.

Parser failures, encrypted members and exhausted work budgets block a clean result when required analysis is incomplete.

Parser isolation, static analysis only. Windows parser workers use bounded IPC and Job Object resource limits. No scanned code is executed.

03 / PLATFORM & AVAILABILITY

Built for Windows.
Clear about its status.

GTA Guard is a Windows 10 / 11 x64 security preview for supported GTA 5 mods and game files. The Windows application defaults to English, with Persian selectable.

Download available

Public Windows download is available without a password. The current Windows preview is not Authenticode-signed. Download the verified installer from the download page.

Know the limits.

Static analysis cannot reliably recover every encrypted payload, runtime-generated string or hidden target. Unsupported formats and incomplete analysis remain visible in the report.

Accuracy on a representative real-world corpus has not been measured. No perfect-protection claim is made.

A clean result is never a guarantee.
