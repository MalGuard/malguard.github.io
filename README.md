# MalGuard · Official website

The public home of **MalGuard**, an open-source defensive security project for safer game-mod analysis. Created by **Mohammad Reza Azarderakhsh**.

Explore the [live website](https://malguard.github.io/) for product information, documentation, local tools and current release availability.

## Our principle

**Inspect before you trust.** Security tooling should explain the evidence, the uncertainty and its own limits. A clean scan cannot guarantee that a file, mod or destination is harmless.

For contributions to the security core and responsible vulnerability reporting, consult its [contribution guidelines](https://github.com/MalGuard/malguard-core/blob/main/CONTRIBUTING.md) and [security policy](https://github.com/MalGuard/malguard-core/blob/main/SECURITY.md).
