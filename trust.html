Security & Trust

LOCAL-FIRST

Privacy

Supported scanning is designed to stay on the user's device by default. Optional network features may look up metadata such as hashes, but a file itself must not be sent to a third party without an explicit action and clear disclosure.

Read the privacy summary →

FAIL-CLOSED

Security architecture

The core uses bounded parsing, integrity checks, worker isolation, and fail-closed verdicts. Missing required evidence should become inconclusive instead of being silently treated as safe.

UNSIGNED PREVIEW

Code signing

The current Windows preview is not Authenticode-signed. MalGuard's public policy forbids presenting an unsigned build as signed or equivalent to a future signed release.

Verify what you download.

Known limitations

A clean result is not a guarantee.

Detection coverage

  • No scanner can prove that a file is harmless.
  • Coverage varies by file type, archive structure and available analysis layers.
  • Threat-intelligence coverage is not universal.

Platform coverage

  • Windows-only isolation features are not available in the iPhone browser preview.
  • Some deeper archive and behavioral capabilities remain under development.
  • Unsigned previews may trigger operating-system trust warnings.
Vulnerability disclosure

Report security problems privately first.

Include the affected version or commit, harmless reproduction steps, expected behavior and observed behavior. Do not attach or upload real malware.
