No black box.
Look inside.

The details matter. Explore a real piece of local analysis: a SHA-256 fingerprint, calculated right here in your browser.

A fingerprint identifies bytes. It does not tell you whether a file is safe.

Explore the source ↗
local-fingerprint.jsJAVASCRIPT
// Your browser. No upload.
const sample = 'MalGuard demo — local only.';
const bytes = new TextEncoder().encode(sample);
const digest = await crypto.subtle.digest(
  'SHA-256', bytes
);
const fingerprint = [...new Uint8Array(digest)]
  .map(byte => byte.toString(16).padStart(2, '0'))
  .join('');

// Fixed benign input; nothing leaves this browser.
const bytes = new TextEncoder()
  .encode('MalGuard demo — local only.');
const digest = await crypto.subtle.digest('SHA-256', bytes);
const fingerprint = [...new Uint8Array(digest)]
  .map(byte => byte.toString(16).padStart(2, '0'))
  .join('');

A reproducible identity, not a malware verdict. Identical bytes produce the same fingerprint.
