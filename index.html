Rules & safety

Before using a release

  • Download MalGuard only from an official MalGuard release source.
  • Keep a backup of original game files before changing or installing mods.
  • A scan reduces risk but cannot guarantee that every possible threat is detected.
  • Follow the game, platform and mod creator rules that apply to the files you use.
  • Do not upload private, personal or confidential files for analysis.
  • When a release is published, verify its version and integrity information before running it.

PRODUCT PREVIEW

GTA Guard

MalGuard's first product, focused on security analysis for GTA 5 mods and supported game files.

What is GTA Guard?

GTA Guard is designed to inspect GTA 5 mod files before you use them and present understandable security findings.

Security analysis

The product is designed around multiple analysis layers instead of one simple file check.

  • File and type identification
  • Rule-based security analysis
  • Multi-layer analysis
  • Suspicious indicator aggregation
  • Final security verdict

Supported files

Initial support focuses on common GTA mod formats and archive-based packages.

.ASI.DLL.ZIPGTA Mod Archives

Standard vs Pro

Two levels are planned for the same GTA Guard product.

  • Standard: faster, lighter analysis
  • Pro: deeper multi-layer analysis
  • Both produce a clear security result

How to use

When the release is published:

  • Download GTA Guard from the official release
  • Open GTA Guard
  • Select a supported GTA mod/file
  • Choose Standard or Pro analysis
  • Review the security result
