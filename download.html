Changes in version 1.3.1

    How signed threat updates work

    MalwareBazaar data is collected by the update publisher and delivered as a signed threat list. MalGuard verifies the publisher signature and rollback protection before accepting it. The record count can grow; it is not proof that a file is safe.

    Automatic updates run daily at 03:00 in the Windows local time zone while the computer is on. A missed scheduled run can start later. Manual refresh needs administrator approval to write the protected shared update cache; an ordinary scan does not.

    The status shows authenticated record count, list age and completeness. A stale, unavailable or invalid list blocks SAFE.

    Before you install

    Windows 10 or 11, 64-bit x64, administrator approval and an internet connection for the initial signed intelligence update. Microsoft WebView2 is installed from its verified Microsoft-signed prerequisite when needed. A Python installation is not required.

    macOS, Linux, Android and iOS scanner installers are not provided by this Windows release. A web page or website-wrapper app is not the Windows detection engine.

    Install version 1.3.1 in four steps

    1. Download from this page.

      Enter the website password, close the old MalGuard window and save the verified Windows EXE. No extraction or device license is needed.

    2. Verify the file.

      Open PowerShell in your download folder and run the command below. The result must exactly match this page.

      Get-FileHash -Algorithm SHA256 .\MalGuard-Setup-x64.exe
    3. Run the installer.

      Open the verified installer and approve the Windows administrator prompt if you intend to install it. Keep the default protected installation folder. Setup displays its real installation stages. Scanner self-test and the first signed intelligence update each have a 60-second deadline. A failed first update is reported without an indefinite wait; refresh it inside MalGuard before relying on a SAFE result.

    4. Open MalGuard and inspect a mod.

      Select English or Persian, check the online intelligence status, choose a file and start a static scan. Review evidence and incomplete stages before deciding whether to install the mod.

    Installation and scan troubleshooting

    Blue “Windows protected your PC” screen

    This unsigned preview may be unknown to Microsoft Defender SmartScreen. Verify the exact SHA-256 and source first. For the ordinary unrecognized-app reputation warning, Windows may offer “More info”, then “Run anyway”. Continue only if you intentionally trust this verified release. This does not apply to a named malware detection, a tampered file, an organization policy block or Smart App Control.

    Microsoft SmartScreen guidance
    Smart App Control or organization policy blocks installation

    Smart App Control is different from SmartScreen and may block an unsigned app without a per-app exception. Do not disable protection or organization policy. Ask your administrator or wait for an appropriately signed release. Devices restricted to Microsoft Store apps cannot install this outside-Store preview.

    Microsoft Smart App Control guidance
    Download integrity check failed

    Discard that download and retry from this page. Do not run a partial file or a file whose SHA-256 differs. A proxy, interrupted transfer or stale browser page may cause a mismatch.

    Installation stops or reports an error

    Record the exact message. Check administrator approval and available disk space, close the previous app and retry the verified installer. If WebView2 or the first signed update fails, check your connection and system date. Do not turn off antivirus protection.

    The installer writes bounded diagnostics to the location below. Share the error text with support after removing personal paths and secrets.

    %LOCALAPPDATA%\MalGuard-install-error.txt
    The app does not open after installation

    Start MalGuard from its desktop shortcut. If no window appears, record any Windows event or security message and contact support. A completed installer alone is not proof that every laptop configuration can start the app.

    INVALID, INCONCLUSIVE or stale intelligence

    INVALID describes an absent or malformed expected file structure; plain text renamed to ASI is not a Windows plugin. INCONCLUSIVE means required analysis was incomplete. Encrypted members, unavailable parsers and exhausted work budgets block SAFE. Refresh signed intelligence if the online status is stale.
